# Project 'Prediction of final steel temperature at a steel production plant'
One-sentence overview

### Problem 
По историческим данным о процессе плавления стали на металлургическом предприятии необходимо предсказать финальную температуру стали.

### Data
Данные находятся в нескольких датасетах:<br>
data_arc_new.csv — данные об электродах;<br>
data_bulk_new.csv — данные о подаче сыпучих материалов (объём);<br>
data_bulk_time_new.csv — данные о подаче сыпучих материалов (время);<br>
data_gas_new.csv — данные о продувке сплава газом;<br>
data_temp_new.csv — результаты измерения температуры;<br>
data_wire_new.csv — данные о проволочных материалах (объём);<br>
data_wire_time_new.csv — данные о проволочных материалах (время).<br>
Столбец 'key' во всех датасетах содержит номер партии, при этом может быть несколько строк с одинаковым значением 'key', в этом случае соответствующая партия проходила несколько итераций обработки.

### Aprroach
Для решения задачи необходимо провести исследовательский анализ данных, предобработку данных (проверка на дублирующие записи, нетипичные значения, пропуски данных, неверно определенные типы данных, работа с выявленными проблемами), сформировать датасет с данными по каждой партии (начальная температура, данные производственных этапов, финальная температура партии), провести анализ на мультиколлинеарность и важность признаков, определить модель предсказания финальной температуры стали на основе признаков.
